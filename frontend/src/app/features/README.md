# Angular feature modules

Create independent features here (e.g. `learning-path`, `learning-tasks`, `mentor-dashboard`).
Within a feature, prefer `domain/`, `application/`, `infrastructure/`, `components/`, `pages/` as needed.
See [Module Template](../../../../docs/architecture/MODULE_TEMPLATE.md).

Release 0.1 deliberately contains only preview screens. Do not introduce fake real apprentice profiles or bypass role-based authorization.
